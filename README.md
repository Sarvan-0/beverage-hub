# 🥤 Beverage Hub

A RESTful beverage management API built with **Python, Flask, Flask-SQLAlchemy, and SQLite**.

Beverage Hub provides API endpoints to create, retrieve, and delete beverage records stored in a SQLite database.

## 🚀 Features

- Get all beverages
- Get a beverage by ID
- Add a single beverage
- Add multiple beverages at once
- Delete a beverage
- JSON API responses
- SQLite database persistence
- Pretty-formatted JSON responses
- Tested using Postman

## 🛠️ Tech Stack

- **Python 3**
- **Flask**
- **Flask-SQLAlchemy**
- **SQLAlchemy**
- **SQLite**
- **Postman**
